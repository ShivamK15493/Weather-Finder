<h2>Project Description</h2>

This is a Weather Application built using HTML, CSS, and JavaScript.
The application fetches real-time weather data and displays important 
weather details for a searched location in a simple and user-friendly interface.

<h2>Features</h2>
<ul>
<li>Displays current temperature</li>
<li>Shows humidity level</li>
<li>Shows wind speed</li>
<li>Shows Pressure</li>
<li>Real-time weather updates</li>
<li>Easy-to-use search functionality</li>
</ul>

<h2>Technologies Used</h2>

<ul>
<li>HTML - for structuring the application</li>
<li>CSS - for styling and layout</li>
<li>JavaScript - for fetching weather data and updating the UI dynamically</li>
</ul>

<h2>How It Works</h2>
<ol>
 <li>User enters the name of a city.</li>
 <li>JavaScript fetches weather data from a weather API.</li>
 <li>The application displays temperature, humidity, Pressure and wind speed instantly.</li>
</ol>

<h2>Conclusion</h2>
This project helped me understand how to work with APIs, handle 
JavaScript fetch requests, and build an interactive web application
using core web technologies.
